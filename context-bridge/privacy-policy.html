Privacy Policy

Last Updated: January 29, 2026

Key Points:
  • All data is stored locally on your device
  • All data is encrypted with your passphrase
  • No data is transmitted to external servers
  • No analytics or tracking is performed

Overview

Context Bridge is a browser extension that helps users transfer conversation context between AI chat platforms. This privacy policy explains what data the extension accesses, how it's handled, and your rights.

Data Collection

What We Access

Context Bridge accesses the following data only when you explicitly click "Capture Context":

Data Type Purpose Storage
Conversation text Transfer between AI platforms Local, encrypted
Platform URL Identify source platform Local, encrypted
Timestamp Organize saved contexts Local, encrypted

What We Do NOT Collect

  • Personal account information
  • Login credentials
  • Browsing history
  • Usage analytics
  • Telemetry data
  • Cookies or session tokens

Data Storage

Local Storage Only

All captured context is stored exclusively in your browser's local storage using Chrome's Storage API. Data never leaves your device unless you:

  • Manually export it using the Export feature
  • Manually inject it into another AI platform

Encryption

All stored data is encrypted using:

  • Algorithm: AES-256-GCM (authenticated encryption)
  • Key Derivation: PBKDF2 with 100,000 iterations
  • Salt: Unique random salt per encryption operation

Your passphrase is never stored. Only a derived key hash is kept in session storage to verify subsequent access, and this is cleared when you close your browser.

Data Sharing

We Do Not Share Data

Context Bridge does not transmit data to any servers, share data with third parties, use data for advertising, or sell or monetize user data in any way.

Permissions

Permission Purpose
storage Save encrypted contexts locally
activeTab Read conversation from current tab when capturing
scripting Inject content script for capture/inject functionality
Host permissions Access specific AI platform domains only

Your Rights

Access Your Data

  • View all saved contexts through the extension popup
  • Export your data at any time using the Export feature

Delete Your Data

  • Delete individual contexts from the popup
  • Click "Clear All Data" to permanently delete everything
  • Uninstalling the extension removes all stored data

Security Measures

  • Encryption at Rest: All data encrypted with AES-256-GCM
  • No Network Requests: Extension makes no external API calls
  • Session Isolation: Encryption keys cleared on browser close
  • Minimal Permissions: Only essential permissions requested
  • Open Source: Code available for security audit

Changes to This Policy

We may update this privacy policy to reflect changes in the extension or legal requirements. Significant changes will be noted in the extension update notes.

Quick Summary

Is my data sent to servers? No - all local
Is my data encrypted? Yes - AES-256-GCM
Can you see my data? No - we have no access
Is there tracking/analytics? No - none
Can I delete my data? Yes - anytime
